# 실제 웹사이트 전환을 위해 필요한 자료

마지막 점검일: 2026-08-14

이 문서는 임시 공개 사이트를 독립 도메인의 실제 웹사이트로 전환할 때 필요한 자료를 한곳에서 관리하기 위한 체크리스트입니다. 공개 가능한 정보만 GitHub에 기록하고, 자격증 원본·계약서·상담 기록·토큰은 저장하지 않습니다.

## 1. 현재 확인된 자료

| 항목 | 상태 | 현재 내용 |
| --- | --- | --- |
| 브랜드명 | 확인 | 새벽별 심리상담센터 |
| 브랜드 소개 | 확인 | 심리상담·놀이치료를 제공하며 아이, 부모, 개인의 고유함을 함께 고민 |
| 공식 로고 | 임시 사용 가능 | 네이버 프로필의 200×202 PNG. 실제 오픈 전 고해상도 원본 필요 |
| 네이버 블로그 | 연결 완료 | `dawnstar_mindtherapy` 공개 RSS와 최신 글 |
| 인스타그램 | 프로필 연결 | `@dawnstar_mindtherapy`; 게시물 자동 연결은 공식 API 설정 필요 |
| 공개 노션 | 연결 완료 | ‘심리상담 가이드 _by 새벽/아오리’ |
| 주요 서비스 | 일부 확인 | 개인·커플/부부·놀이치료/양육·심리평가·트라우마/애착 |
| 상담 접근 | 일부 확인 | AEDP, SP 등 정서·애착·신체 기반 관점 |
| 활동 자격 | 일부 확인 | 공개 노션 기준 한국상담심리학회 상담심리사 자격으로 활동 |
| 공개 사이트 | 운영 중 | Sites의 현재 production deployment URL |

## 2. 정식 공개 전에 반드시 필요한 자료

아래 항목은 실제 웹사이트의 신뢰도, 예약 전환, 법적 안내에 직접 영향을 줍니다. 구체적인 값은 [`site-information-form.md`](./site-information-form.md)에 작성합니다.

### 기관 기본 정보

- [ ] 공개할 대표자 또는 상담자 이름과 표기 방식
- [ ] 사업자/기관의 정확한 상호명
- [ ] 사업자등록번호 공개 여부와 공개 문구
- [ ] 센터 주소, 건물명, 층·호수
- [ ] 대중교통, 주차, 엘리베이터 등 방문 안내
- [ ] 대표 전화·이메일·카카오톡/네이버 예약 중 공식 문의 채널
- [ ] 운영 요일, 상담 가능 시간, 평균 답변 시간

### 상담자 전문성

- [ ] 최종 학력과 전공 중 공개할 범위
- [ ] 자격명, 발급기관, 등급, 취득연도
- [ ] 학회 소속과 현재 상태
- [ ] 주요 수련, 교육, 슈퍼비전 경력
- [ ] 주요 상담 분야와 대상 연령
- [ ] 공개 가능한 경력·강의·제휴 이력
- [ ] 얼굴 사진 공개 여부와 최종 프로필 문장

자격증 이미지나 번호 전체는 GitHub에 올리지 않습니다. 웹사이트에는 검증에 필요한 최소 정보만 표시합니다.

### 서비스와 비용

- [ ] 서비스별 대상과 포함 범위
- [ ] 1회 상담 시간과 권장 빈도
- [ ] 대면/화상/전화/채팅 가능 여부
- [ ] 초기상담, 개인상담, 부부상담, 놀이치료, 심리검사 가격
- [ ] 검사 종류별 비용·소요시간·결과상담 포함 여부
- [ ] 결제수단과 현금영수증/증빙 안내
- [ ] 변경·취소·노쇼·환불 기준
- [ ] 미성년자 상담 시 보호자 동의와 안내 방식

### 법적·안전 안내

- [ ] 개인정보 처리 주체와 문의처
- [ ] 문의 과정에서 수집하는 정보, 목적, 보관기간, 파기 방법
- [ ] 네이버·인스타그램·예약 도구 등 외부 서비스 이용 고지
- [ ] 위기상황·자해/타해 위험·응급상황에서는 제공하지 못하는 범위
- [ ] 의료기관이 아닌 경우 진단·처방을 대신하지 않는다는 문구
- [ ] 콘텐츠 저작권과 인용·재사용 기준
- [ ] 후기·제휴·언론 자료 게시 동의 또는 출처 확인

## 3. 완성도를 높이는 권장 자료

### 브랜드 자산

- [ ] 투명 배경 PNG 로고(최소 1,000px)
- [ ] SVG 또는 AI 원본 로고
- [ ] 가로형·세로형·아이콘형 로고 변형
- [ ] 사용할 정확한 브랜드 색상 코드
- [ ] 상업적 웹 사용이 가능한 한글·영문 폰트
- [ ] 상담자 프로필 사진 2~3장
- [ ] 상담실 전경·대기 공간·건물 입구 사진
- [ ] 제휴사 로고 사용 허가와 원본

### 검색과 채널 운영

- [ ] 사용할 독립 도메인 후보 2~3개와 DNS 접근 권한
- [ ] 네이버 서치어드바이저 계정
- [ ] Google Search Console 계정
- [ ] 방문 분석 도구 선택과 개인정보 문구
- [ ] 지도·예약 서비스 링크
- [ ] Instagram Business/Creator 계정과 Meta 앱 연결
- [ ] 사이트에 우선 노출할 대표 블로그 글 6~10개

## 4. 두 번째 단계에서 결정할 기능

- [ ] 웹사이트 안에서 직접 예약 신청
- [ ] 일정 선택과 자동 확인 메시지
- [ ] 온라인 결제 또는 예약금
- [ ] 뉴스레터/새 글 알림
- [ ] 교육·강의·기관 협업 문의 폼
- [ ] Insight Relay 대기자 등록과 베타 운영
- [ ] 관리자용 콘텐츠 편집 화면

예약·결제·회원 기능은 개인정보와 운영 부담이 커지므로, 실제 공개 1차 버전에서는 외부 예약 링크로 시작하고 운영 방식이 확정된 뒤 추가하는 편이 안전합니다.

## 5. 자료 전달 형식

| 자료 | 권장 형식 | 저장 위치 |
| --- | --- | --- |
| 공개 문구·가격·정책 | `site-information-form.md` | GitHub 가능 |
| 로고·사진 | PNG/JPG/WebP 원본 | 공개 사용 승인된 파일만 GitHub |
| 자격 증빙 원본 | PDF/JPG | 비공개 보관, GitHub 금지 |
| API 토큰·비밀번호 | 환경 변수 | GitHub 금지 |
| 상담 기록·문의 내역 | 원본 시스템 | GitHub 및 공개 사이트 금지 |

## 6. 권장 진행 순서

1. 기관 기본 정보와 공식 문의 채널 확정
2. 상담자 정보, 서비스 시간·가격·취소 규정 확정
3. 개인정보·위기상황·콘텐츠 이용 문구 확정
4. 고해상도 로고와 사진 전달
5. 독립 도메인 구매 및 연결
6. 모바일·검색·예약 동선 최종 검수
7. 정식 공개 후 블로그·노션·인스타그램 운영 루틴 적용

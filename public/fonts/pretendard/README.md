# Pretendard

Unmodified Pretendard Variable v1.3.9 by Kil Hyung-jin, licensed under SIL Open Font License 1.1. See LICENSE.

Source: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable

Self-hosted official dynamic subsets so reading pages do not send font requests to an external CDN. Unicode ranges allow each page to fetch only the character groups it uses instead of a single 2 MB font. `font-display: swap` keeps text visible while loading. The existing serif brand accents are unchanged.
